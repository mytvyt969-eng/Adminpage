# Prayer Schedule Time — Android TV

Production-oriented Android TV admin editor built with Kotlin and Jetpack Compose.

## Features
- Fajr, Dhuhr, Asr, Maghrib and Isha editing
- Athan time, offset/auto mode and Jama'at time
- Jumu'ah, Eid, Eid-ul-Adha, Taraweeh and Ramzan controls
- Countdown controls
- DPAD-first focus/navigation
- UP/DOWN time and minute steppers
- DataStore persistence
- Save confirmation
- GitHub Actions debug APK build

Open the project in Android Studio and run the **debug** variant on an Android TV/emulator.
